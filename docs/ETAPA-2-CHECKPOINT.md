# Etapa 2 — v36, numai rezumate per meci

Game Night, biblioteca, filtrele, sursele urmărite și salvările din bibliotecă au fost eliminate la cererea utilizatorului. Cheile istorice locale nu sunt șterse automat.

Pagina meciului oferă un rezumat YouTube numai dacă ambele echipe și data din titlu corespund. Sugestiile bazate doar pe publicare nu sunt prezentate drept rezumat confirmat. ESPN apare numai dacă sursa indică recap, nu faze scurte. Căutarea externă după ligă, echipe și data SUA este etichetată explicit; nu este dovadă că un rezumat există. Linkul manual/reset rămâne local.

Colectorul periodic citește cele cinci canale principale ale ligilor și păstrează doar clipuri clasificate ca rezumat. RSS are fereastră limitată: nu garantăm rezumat pentru fiecare meci. Retenție 45 zile, maximum 1500. Cronul pornește automat numai după merge aprobat; nu este testat automat pe preview. Player click-to-load, link extern când embed este restricționat.

Verificări: npm test include cititoare, funcții, ediție personală, video API și render per meci. Fără merge sau producție fără acord explicit. Protecția completă contra spoilerelor este amânată separat.
